Plumbing, HVAC, and invoice codes are built in. This page is the whole app — one HTML file, hosted on the shop site so a phone can open it.

Keep it as a single file. A zip, a Python server, extra CSS, or a folder of scripts will not run as an app on an iPhone or Android.

One file, hosted offsite

iPhone and Android cannot host a folder of files. The code book stays one HTML file on the shop website. Open that link on the phone, then add it to the home screen. You can also save this one file for a local copy — nothing else.

Put it on the phone

1. Open this page from the shop site (Safari on iPhone, Chrome on Android).

2. iPhone: Share → Add to Home Screen.

3. Android: menu → Add to Home screen, or save this file and open it.

4. Lookup uses the codes already inside the file. No extra download.
